# Путеводитель по Кабардино-Балкарии

Статичный лендинг по презентации группы: регион, люди, еда и три дня маршрута. Карта — виджет Яндекс Карт, ключ API не нужен.

## Локально

```bash
python3 -m http.server 4173
```

Открыть http://localhost:4173

## GitHub Pages

1. Залить репозиторий на GitHub.
2. Settings → Pages → Branch: `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://<пользователь>.github.io/<репозиторий>/`.

Файлы лежат в корне, сборка не нужна.
